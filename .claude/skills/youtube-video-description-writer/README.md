# YouTube Video Description Writer

## What it does

This free skill writes finished YouTube descriptions from rough creator notes. You give it a title, topic, and CTA, and it returns two ready-to-paste description options plus a pinned comment, keyword check, and hashtags.

If you have been reusing the same generic description format, this helps you publish faster while still giving each video clear search intent and viewer direction.

## Who it's for

- YouTubers publishing weekly (or more)
- Creators who want better descriptions without spending 20 to 30 minutes per upload
- Anyone searching for an AI YouTube description generator or YouTube description template

## Key features

- Two complete description options with different hooks
- Natural keyword placement without stuffing
- Pinned comment draft that drives replies
- Built-in keyword coverage check and hashtag suggestions
- Upgrade path to a full YouTube SEO workflow

## Example use case

You recorded a tutorial, but upload day is here and you still need description copy. Paste your working title, audience, and CTA. The skill outputs a publish-ready description in minutes so you can ship on time.

## Starter prompts

- `Write a YouTube description for a video titled "How to batch film 5 shorts in one afternoon." Audience: small creators with day jobs. CTA: subscribe for weekly workflow tips.`
- `Generate two YouTube descriptions for my video about "chatgpt for scriptwriting." Keep one version concise and one more detailed.`
- `Use these keywords naturally in a YouTube description: "youtube automation workflow," "content calendar setup," "creator productivity."`

## How to install

1. Open Claude Projects or your custom GPT setup.
2. Upload `SKILL.md` as the instruction file.
3. Start with one of the starter prompts above.
