# TikTok Script Template - Worked Example

## Creator Input

```text
Topic: 3 mistakes new podcasters make
Audience: Beginner podcasters
Goal: Comments
Length: 30 seconds
Tone: Direct
```

## Generated Output

### Hook Options
1. New podcast? Stop making these 3 mistakes.
2. Your podcast is stuck for one reason.
3. Most new podcasters lose listeners here.
4. Better mic will not fix this.
5. If episode one flopped, watch this.

### Primary TikTok Script
- 0:00-0:03 Hook: "New podcast? Stop making these 3 mistakes." | Visual: text pop-in "3 mistakes"
- 0:03-0:10 Setup: "I see these in almost every new show." | Visual: quick editing timeline cuts
- 0:10-0:22 Value: "One: no episode structure. Two: long intros. Three: random posting schedule." | Visual: numbered overlays
- 0:22-0:28 Proof or punch: "Fix these and your first 10 episodes improve fast." | Visual: simple up-arrow graphic
- 0:28-0:30 CTA: "Which one are you doing right now?" | Visual: comment bubble cue

### On-Screen Text Plan
- 3 Podcast Mistakes
- No Structure = Drop-off
- Long Intro = Swipe
- Random Posting = No Momentum
- Which one is yours?

### Comment Bait Line
1. Which mistake is hardest to fix?
2. Want part 2 with exact fixes?

### Caption Draft
New podcasters: fix these 3 mistakes first. #PodcastTips #CreatorGrowth #ContentStrategy
