# TikTok Script Template

## What it does

This free skill generates TikTok-native scripts you can film immediately. It outputs hooks, a timestamped script, on-screen text, comment bait lines, and a short caption with hashtags.

It is built for speed: you give a topic and goal, it gives a structured script in minutes.

## Who it's for

- Creators posting TikTok content consistently
- Anyone stuck on hooks and first lines
- Social teams that need short-form drafts fast

## Key features

- 5 hook options per topic
- Timestamped script beats for 15 to 60 second formats
- Platform-native pacing (not recycled Reels structure)
- Comment-driving CTA support
- Fast upgrade path to full short-form workflow

## Example use case

You want to post today but your script still is not ready. Paste your topic and audience, pick one hook option, and film from the timestamped script without rewriting everything.

## Starter prompts

- `Write a 30-second TikTok script on "how to find podcast guests" for solo creators.`
- `Create a TikTok script template for "AI tools for newsletter writers" with a direct tone and comment CTA.`
- `Give me 5 TikTok hooks and one full script for "I stopped overediting and got better retention."`

## How to install

1. Upload `SKILL.md` to your Claude Project or custom GPT instructions.
2. Start with a starter prompt.
3. Choose one hook and record directly from the script beats.
